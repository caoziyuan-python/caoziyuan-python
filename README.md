## 🥚 最近正在孵化

### 🫀 PulsePlan｜一个会“看状态”的任务规划Agent

我最近在想：

> 为什么所有任务管理工具都默认，早上九点和凌晨一点的我是同一个人？

怎么结合可穿戴设备（比如apple watch）采集的心率、HRV、睡眠、活动状态等信号，
在我授权的前提下估计我本人（一个偶尔精力无限，长期精力有限）当前的精力与负荷，并结合任务的优先级、
截止时间、难度和预计耗时，动态调整我今天的整体计划。

例如：

- 精力充足时，优先处理需要深度思考的任务；
- 状态下降时，将复杂任务拆成更容易开始的小步骤or直接放轻松简单不动脑的日程任务给我；
- 连续高负荷后，不再继续塞任务，而是建议休息或切换轻量工作；
- 临时任务进入后，重新规划当天安排，而不是把它简单堆进待办列表。
- 不要再让我用各种借口完不成今天的计划or放弃原有的健身安排

理想中的执行链路是：

> 生理与行为信号 → 状态估计 → 任务理解 → 动态规划 → 用户确认 → 反馈学习

它不应该根据一次心率变化就武断地说“你焦虑了”，  
也不应该偷偷替用户决定一切，但是实现起来需要点时间和数据。

我更希望它是一个**尊重隐私、允许纠偏、解释得清楚的、懂得如何结合J人清晰计划的基础上保留我们这些P人的不确定性。**：

> 不是监督你完成更多事情，而是帮助你在不同状态下做更合适的事情。

**关键词：** Wearable Sensors · Context-aware Agent · Dynamic Planning · Human-in-the-loop · Privacy
